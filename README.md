# Waveform Drawer

プレゼン資料用のタイミングチャート（波形図）を描くためのツールです。HTML ファイル 1 つで動き、インストールは不要です。

## 使い方

`index.html` をブラウザ（Chrome / Edge 推奨）で開きます。

| モード | 操作 |
|---|---|
| 波形 `1` | デジタル：マスをクリック/ドラッグで High⇔Low。アナログ：クリックで点追加、ドラッグで移動、ダブルクリックで削除 |
| 寸法線 `2` | 横にドラッグして時間の寸法線を引く（「1マス = ○ms」設定でラベル自動表示） |
| 矢印 `3` | 原因の変化点から結果の変化点へドラッグ |
| 区切り線 `4` | クリックで縦線を追加、ラベルを付けられる |

- 「画像をコピー」（`Ctrl+C`）で PowerPoint などにそのまま貼り付け
- 「PNG保存」で画像出力（等倍〜4倍、背景透明可）
- 「保存」/「開く」で JSON として再編集可能
- エッジの傾きを 0 にすると直角の波形になります
